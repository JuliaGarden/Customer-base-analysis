# Customer-base-analysis
Учебный аналитический кейс, посвященный анализу клиентской базы, проникновения банковских продуктов и эффективности маркетинговых коммуникаций.

Проект состоит из двух частей:
- анализ клиентской базы и проникновения банковских продуктов
- анализ эффективности маркетинговых спецпредложений

## Используемые инструменты
- Microsoft Excel
- Pivot Tables
- Microsoft PowerPoint

## Часть 1. Анализ проникновения банковских продуктов

### Цель - оценка динамики численности клиентов и уровня проникновения продуктов в двух категориях клиентов, а также выявление потенциальных точек роста продуктового портфеля.

### Выполнено
- рассчитана динамика количества клиентов;
- рассчитано проникновение банковских продуктов по месяцам;
- выполнено сравнение двух клиентских сегментов;
- проанализированы продукты:
  - кредит;
  - эквайринг;
  - лизинг;
  - банковские гарантии;
  - зарплатный проект;
- выявлены точки роста продуктового портфеля;
- подготовлены бизнес-рекомендации.

### Основные выводы
- обе клиентские категории демонстрируют рост;
- эквайринг является самым распространенным продуктом;
- зарплатный проект и лизинг обладают низким уровнем проникновения;
- между категориями клиентов существуют существенные различия в использовании отдельных продуктов.


## Часть 2. Анализ эффективности маркетинговых коммуникаций

### Цель - оценка эффективности различных каналов коммуникации и типов специальных предложений.

### Выполнено
- построены воронки конверсии;
- рассчитаны CTR и конверсия в активацию;
- проведено сравнение каналов:
  - PUSH;
  - SMS;
  - EMAIL;
  - контрольная группа;
- проанализировано влияние типа предложения;
- рассчитан эффект маркетинговой кампании относительно контрольной группы.

### Основные выводы
- PUSH показал максимальную конверсию в активацию;
- SMS обеспечивает высокий уровень прочтения;
- EMAIL практически не отличается от контрольной группы;
- тип предложения оказывает меньшее влияние, чем канал коммуникации.


## Результат
По итогам анализа были сформулированы рекомендации по развитию банковских продуктов и повышению эффективности маркетинговых коммуникаций.
